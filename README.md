# Portfolio Website

A personal portfolio website built as **Project 2 of the Udacity Front End Web Developer Nanodegree**.

The project focuses on organising and styling a portfolio website using HTML, Sass/SCSS and JavaScript, with a modular stylesheet structure.

## Technologies Used

- HTML5
- CSS3
- Sass/SCSS
- JavaScript
- npm

## Project Structure

```text
.
├── dist/
│   └── main.css
├── src/
│   ├── img/
│   │   ├── profile-photo.jpg
│   │   ├── project-1.jpg
│   │   ├── project-2.jpg
│   │   └── project-3.jpg
│   ├── js/
│   │   └── main.js
│   ├── scss/
│   │   ├── base/
│   │   ├── blocks/
│   │   ├── utils/
│   │   └── main.scss
│   └── index.html

```

## Development Approach

The SCSS code is organised into smaller partials for areas such as typography, resets, animations, buttons, cards, the header, footer, introduction and project sections.

This structure helps separate styling concerns and makes the stylesheet easier to maintain.

## Running the Project

See `package.json` for the available scripts and build instructions.

## Learning Outcomes

This project provided practical experience with:

- Structuring a frontend website using HTML.
- Organising stylesheets with Sass/SCSS.
- Separating styling into reusable, purpose-specific partials.
- Working with JavaScript alongside HTML and CSS.
- Organising image assets and source files in a project directory.
